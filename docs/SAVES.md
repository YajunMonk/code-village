# 存档与常见问题

## 进度保存在哪里？

游戏使用浏览器的 `localStorage`。主线推进、对话与室内探索会触发保存，街道上也有定时自动保存；「设置与存档」支持立即保存。

不同设备、浏览器、浏览器配置，以及不同协议、域名或端口，分别保存。官网、GitHub Pages 和本地地址不共享进度。退出隐私浏览或清理网站数据，也可能删除本机存档。

## 怎样备份、换手机或换电脑？

1. 在首页打开「设置与存档」，或游玩时从暂停菜单进入「存档管理」。
2. 点击「导出备份」，保存生成的 JSON 文件。
3. 将文件传到另一台设备，打开游戏并进入同一面板。
4. 选择存档文件，核对章节、术语数量与保存时间，确认后导入。

支持系统分享的浏览器还提供「分享存档」，也可以使用下载文件。

导入前会备份当前本机进度。「恢复上次导入前的进度」可恢复最近一次导入前的状态。文件会先经过格式、字段和大小校验，取消预览不会覆盖现有进度；写入失败时会尝试恢复旧数据。

## 刷新或更新游戏会丢档吗？

普通刷新和在同一网址更新资源不会主动清空存档。开始新冒险会要求确认。浏览器无法保存时，游戏会显示失败信息；可以先导出当前进度再处理。

兼容旧 demo 的存档标识 `code-village-v3`，新增字段在读取时补齐，不要求玩家手动改文件。

## 下载后为什么建议开本地服务？

网页包包含独立图片，推荐通过 `python3 scripts/serve.py --open` 运行，避免浏览器的本地文件限制。

离线单文件版内嵌全部素材，可以直接打开；但各浏览器对 `file://` 存储的处理不同。需要长期保存时，推荐固定的本地服务地址，并定期导出备份。

## 需要 AI 账号、API Key 或联网付费吗？

不需要。小 A、终端、订单系统与上线流程是游戏内的教学模拟，不会调用外部 AI、实际发送订单或部署真实服务。

## 画面未加载或操作有问题？

先等待首屏资源加载完成。看到“轻点或按空格重试”时可重新尝试。在线版首次加载需要下载美术资源；网页发行包必须完整保留 `assets/`。

反馈时请提供浏览器、设备、横竖屏、发生位置、操作步骤和截图。存档文件不必公开；如排查需要，请先确认其中只有你愿意分享的游戏进度。
