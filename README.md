# 代码村大冒险（像素风氛围编程入门游戏）

一个给 0 基础新手玩的像素风冒险游戏。凌晨 2 点，你问 AI "帮我做个点单 App"，它回了一大堆 React、RAG、MCP……你看不懂，被吸进了电脑里的【代码村】。你要和 AI 实习生小 A 一起，一边帮村民做出你的"鸭鸭点餐 App"，一边听懂这些行话，最后打败黑话魔王，从上线之门回家。

**目标不是教你写代码，而是让你听懂 AI 和程序员在说什么。**

- **在线玩**：https://yajunmonk.github.io/code-village/
- **本地玩**：下载本仓库的 `index.html`，双击用浏览器打开即可，不需要安装任何东西。
- **时长**：主线约 30–45 分钟；找齐隐藏村民、刷成就再多一些。
- **存档**：每过一关、每 15 秒自动存档，暂停菜单里也能手动"保存进度"。进度只存在你自己的浏览器里，不需要登录任何账号（换浏览器或清除网站数据会丢）。

### 怎么操作

| | 电脑 | 手机 |
|---|---|---|
| 走路 | 方向键 / WASD（按住 Shift 跑） | 屏幕上的方向键（"跑"键加速） |
| 说话、翻页 | 空格 / 回车 | A 键，或点对话框 |
| 术语图鉴 | C 键，或右上角图鉴按钮 | 右上角图鉴按钮 |
| App 进度 | 右上角手机按钮 | 右上角手机按钮 |
| 暂停（换帽子、调声音） | Esc | 右上角菜单 |

### 能学到什么（5 章 27 关，42 个术语 + 6 个隐藏术语）

| 章节 | 术语 | 小游戏 | 守关怪 |
|---|---|---|---|
| 第一章 · 点子工坊 | 氛围编程、程序、Bug、需求、原型、MVP、迭代 | 泡面排序、MVP 背包（只有 3 格） | 需求迷雾怪 |
| 第二章 · 网络小镇 | 前端、HTML/CSS/JS、浏览器、后端、数据库、服务器、API、JSON、状态码、框架、登录与权限 | 饭馆分活儿、送餐柜台快问快答 | 404 幽灵 |
| 第三章 · AI 研究所 | 大模型、提示词、多模态、上下文、Token、幻觉、知识库（RAG）、微调、智能体、MCP | 提示词工坊、AI 记事本、幻觉侦探、图书馆开卷考试、智能体排步骤 | 幻觉狐狸 |
| 第四章 · 工程工坊 | Git、分支、GitHub、依赖、密钥、环境变量、报错和日志、测试 | 找回正确的存档、读报错 | 合并冲突双头龙 |
| 第五章 · 发射台 | 本地、端口、域名、部署、回滚、和 AI 协作 | AI 黑话翻译、发射前检查、终端 git push、火箭发射 | 线上事故火龙、黑话魔王 |

- **隐藏村民**（头上有蓝色 ? 的人）：响应式、缓存、Cookie、向量数据库、开源、注释。
- **每张术语卡**都有：一个生活类比（"前端像饭馆的大堂"）、一段大白话解释、一句"AI 可能会这么说"的例句。
- **结局**：把一路学的东西拼成鸭鸭点餐 App 的全景图（浏览器 → 前端 → API → 后端 → 数据库，加上 AI 客服和上线），打开上线之门。
- **成长**：每打败一只守关怪，鸭鸭点餐 App 就升级一次（从一个想法 → 草图 → 能下单 → 有 AI 客服 → v1.0 → 正式上线），小 A 还会得到一顶新帽子。
- **12 个成就**：一次写出完美提示词、识破所有幻觉、读完全部告示牌……

### 画面和声音

- 中文像素字体（Fusion Pixel，SIL 开源字体许可，见 `FONT-LICENSE.txt`），所有界面都画在游戏画面里。
- 27 个区域，从清晨的池塘一路走到黑话魔王城和黎明之丘：动态光影、迷雾、狐火、熔岩、乱码墙。
- 自制芯片音乐合成器：村庄、研究所、夜晚、发射台、Boss 战、最终战、黎明结局各有曲子，全程循环播放；手机切后台或锁屏回来后，点一下就会自动接着放。
- 电脑、手机竖屏、手机横屏都能玩，画面按整数倍放大，像素清晰。

### 文件结构

```
index.html          打包好的游戏（双击就能玩）
source/
├── build.py          打包脚本（需要 pip install fonttools brotli）
├── src/              源代码
│   ├── shell.html    网页外壳和触屏按键
│   ├── 00_core.js    缩放、输入
│   ├── 10_audio.js   芯片音乐合成器和音效
│   ├── 20_art.js     角色像素画
│   ├── 21_props.js   树、房屋、道具、图标
│   ├── 22_art3.js    小 A、守关怪、帽子、新道具和术语图标
│   ├── 30_world.js   27 个区域的地图、地面、光照、粒子
│   ├── 35_entities.js 玩家、同伴、村民、镜头、HUD
│   ├── 40_ui.js      文字、窗口、按钮、对话框
│   ├── 50_screens.js 标题、术语卡、图鉴、App 进度、成就、暂停、结局
│   ├── 51_puzzles.js 选择题、排序题、守关怪战斗、终端
│   ├── 52_games.js   挑选、快问快答、提示词工坊、幻觉侦探、全景图、发射
│   ├── 60_story.js   术语、成就、剧情和台词
│   └── 70_main.js    主流程
└── assets/           字体开源许可
```

改了 `source/src/` 里的代码之后，运行 `python3 source/build.py` 重新生成 `index.html`。打包时只保留游戏里用到的字，字体只有约 50KB。
